核心規則

中間交叉：垂直棍 (Vx) 永遠壓在水平棍 (Hx) 上方

末端交叉：水平棍 (Hx) 末端永遠壓在垂直棍 (Vx) 上方

H 斜插法

Hn-R 下緣離內側 h+y/2 距離處，壓在 V(n-1) 右上角，向右下延伸，上緣與 Vn 左下角交會。

P 位置公式

Pn = B + (n-1) × (y + s)

  • P1 = v+y/2
  • P2 = v+y/2 + y + s
  • P3 = v+y/2 + 2(y + s)

搭建順序

H1-R (P1) → H1-L (P2) → H2-R (P3) → H2-L (P4)
